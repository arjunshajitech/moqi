Features

Small, fast, and built on the standard

Everything speaks the IETF MoQ Transport wire format, from the Rust relay to the JavaScript in your tab.

Low latency by design

Audio rides QUIC datagrams so a lost packet never stalls the next one. Video groups preempt stale ones.

Rust relay

Tokio + WebTransport over HTTP/3. One upstream subscription per track, fanned out to every viewer.

Camera, mic & screen

WebCodecs VP8 and Opus straight from the browser. Screen share takes the stage automatically.

Instant join

The relay caches the current group, so a late joiner starts at the latest keyframe instead of waiting.

Strict protocol

Validates request IDs, aliases, lengths and versions; unsupported requests get a polite NOT_SUPPORTED.

Tested end to end

Unit tests, byte-for-byte JS↔Rust codec interop, and a headless Chrome call between two tabs.

Quick start

Running in three steps

You need Rust and a recent Chrome or Edge. That's it.

Build

Clone the repo and compile the relay in release mode.

$ git clone https://github.com/arjunshajitech/moqi.git
$ cd moqi
$ cargo build --release

Run

Starts WebTransport on UDP 4443 and the web page on 8080.

$ ./target/release/moqi-relay

Call

Open the page in two tabs, pick a name, and press join.

open http://localhost:8080/?room=demo
Under the hood

Four tracks per participant

Capture time travels in the TIMESTAMP object property, so relays never need to read the media.

videosubgroup streamVP8. One group per GOP: object 0 is the keyframe, one QUIC stream per group.

FAQ

Questions, answered

Which browsers work?

Recent Chrome and Edge. moqi needs WebTransport (with serverCertificateHashes) and WebCodecs. Firefox has fallbacks in the code but is untested.

What is the "Relay URL" under Advanced?

The address of the relay your browser connects to. It defaults to https://<page host>:4443/moq.

Change it only if the relay runs on another port or machine. You can also pass it in the link: ?room=demo&relay=https://host:4443/moq.

Do I need a TLS certificate?

Not for local use. The relay creates a 10-day self-signed certificate and the page trusts it via its SHA-256 fingerprint. For a public server, pass --cert and --key.

Can more than two people join?

The relay supports it: start it with --max-peers 4. The current web UI shows one remote person, so extra participants are ignored by the page.

I hear an echo when testing with two tabs.

Both tabs share your speakers and mic. Use headphones, or mute one tab.

"Address already in use" when starting the relay?

Another relay is already running. Stop it with pkill moqi-relay, or choose other ports with --bind and --http.

Ready to say hi over QUIC?

Build the relay, open two tabs, and you're on a call in under a minute.
